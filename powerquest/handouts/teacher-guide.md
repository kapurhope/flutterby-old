# Teacher guide — Power the City (8th grade)

**Time:** ~45–55 minutes  
**Sim:** Open `powerquest/index.html` in a browser (projector + student devices).

## Goals on the board
1. Reliability (lights on) ≥ 85%  
2. CO₂ ≤ 100  
3. Stay within $100 budget  

## Procedure
| Phase | Time | What to do |
|-------|------|------------|
| Intro | 5 min | Show goals. Demo one slider + one event on the projector. |
| Explore | 15–20 min | Pairs run **two** strategies (use presets, then tweak). Test at least one event. |
| Document | 10 min | Fill scorecard from Saved runs. |
| Mini-debate | 10–15 min | 60–90 sec each; class votes on best balance. |
| Reflect | 5 min | Scorecard reflection: 2 numbers + 1 event. |

## Facilitation tips
- There is **no single correct mix**. Praise clear evidence over “winning.”
- If pairs finish early: try the event they haven’t used yet and note what broke.
- Whole-class only? Project the sim and have rows vote on slider changes.

## Assessment
- Completed scorecard + short reflection citing 2–3 data points.
- Quick look-fors: uses numbers, names a trade-off, mentions an event.

## Files
- `index.html` / `styles.css` / `sim.js` — the mini-sim  
- `handouts/debate-scorecard.md` — print or copy into Google Docs
