# PowerQuest

8th-grade energy mix mini-sim for the **Power the City** lesson.

## Run it

Open `index.html` in a browser (double-click or Live Server). No build step.

## What’s included

- Live goals: reliability ≥ 85%, CO₂ ≤ 100, budget ≤ $100
- Five levers + presets + heat wave / low wind events
- Save two runs for the mini-debate
- Printable scorecard + teacher guide in `handouts/`
