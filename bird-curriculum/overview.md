# Overview — pacing, differentiation, standards anchors

## Suggested calendars

### Compact (6 days)
One module per day, Modules 1–6 in order.

### Comfortable (8–9 days)
- Day 1–2: Module 1 (race + clean data table as a class)  
- Day 3: Module 2  
- Day 4: Module 3  
- Day 5–6: Modules 4–5  
- Day 7–8: Module 6 (explore + debate)  
- Day 9 (optional): outdoor bird count or PowerQuest parallel

### Club / after-school (6 sessions × 60–75 min)
Same sequence; add more mystery cards and a gallery walk of rule posters.

---

## Differentiation by grade

| Move | 5th–6th | 7th–8th |
|------|---------|---------|
| Language | “What rule would a robot use?” | “training data / test data / feature” |
| Rules | 1–2 conditions (“High water AND high plants”) | 3 conditions + “ignore beak color” |
| Exceptions | One surprise location | Surprise + biased dataset + name *which* failure |
| Writing | Sentence starters | Cite 2–3 numbers; propose a better study |
| Math | Counts & tallies | Percents correct; simple “accuracy” |

**Mixed 5–8 room:** pair older/younger; older students own the “bias detective” role in Modules 2 and 5.

---

## Standards anchors (flexible)

Not a full crosswalk — useful talking points for schools:

- **Life science:** adaptations; interdependent relationships; ecosystem dynamics  
- **Science practices:** analyzing data; constructing explanations; arguing from evidence  
- **Computational thinking (unplugged):** pattern recognition; algorithms as rules; evaluating models  
- **Environmental literacy:** human impact; conservation trade-offs  

---

## Safety & inclusion

- Food props are **not for eating** (or use only edible items if you prefer and check allergies).  
- Flood round: shallow trays; wipe spills.  
- Offer non-competitive roles (data recorder, timer, photographer of results).  
- Avoid “smarter kids = better AI”; praise clear rules and honest misses.

---

## Hands-on vs computer-aided

| Prefer hands-on | Prefer computer |
|-----------------|-----------------|
| Modules 1, 3, 5 | Module 6 **FlockQuest** (live trade-offs) |
| Modules 2 & 4 work on paper | Projector/shared doc optional for class data |

If devices fail on Module 6, use the printed capstone scorecard (same math, slower).

## Sister sims

- **FlockQuest** (`flockquest/`) — required for Module 6 bird conservation trade-offs  
- **PowerQuest** (`powerquest/`) — optional parallel day on energy mix trade-offs  

Same debate structure: goals → explore → save two runs → vote → reflect with numbers.
