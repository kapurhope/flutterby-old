# Flutterby Field School
## Bird-themed science for grades 5–8 — hands-on + computer-aided

**Big idea:** Birds survive through adaptations and relationships in ecosystems. Humans (and simple digital tools) can help protect them — but only if we ask good questions, use honest data, and know when our models are wrong.

**Format:** A **series** that alternates **hands-on labs** with **computer-aided** pattern/trade-off work. Computers are used only when they add something paper can’t (live trade-off sim, optional shared tables). Most “AI” thinking is still unplugged.

**Length:** 6 modules × ~45–55 min (expandable to 8–10 periods). Modules 1→2 and 4→5 are tightly linked; Module 6 uses the **FlockQuest** website.

---

## Learning goals

1. Explain how **beak shape + environment** affect survival.  
2. Trace relationships in a bird-centered **food web**.  
3. Build and test **simple prediction rules** from a table (ML-style thinking, no coding required).  
4. Name reasons a model can be **wrong** (small data, bias, useless features, missing factors).  
5. Argue for a **conservation portfolio** using FlockQuest numbers (nest success, neighbors, budget).

| # | Module | Experience | Skill | Deliverable |
|---|--------|------------|-------|-------------|
| 1 | **Best Bird Beak** | Drought & flood beak races | Generate real data | Score sheet |
| 2 | **Teach the Computer** | Rules + mystery birds + noise | Features & prediction | Rule card |

## Materials

**Hands-on kit:** spoons, forks, chopsticks, clothespins, tweezers, cups; beans/rice/rubber bands/pom-poms/paper clips; water tray; yarn; organism cards; timers.

**Computer-aided:** devices or one projector for [FlockQuest](../flockquest/index.html); optional shared spreadsheet for Module 2 class data.

**Print:** everything in `handouts/`.

## Facilitation principles

1. **Hands-on first** when the body teaches the idea (beaks, webs).  
2. **Computer when trade-offs must update live** (FlockQuest) or when projecting data helps.  
3. **Students are the AI first** — no coding required.  
4. **Mess with them on purpose** — exceptions teach bias.  
5. **Celebrate revised rules** — changing your mind with evidence is the win.
