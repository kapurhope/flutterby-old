Module 4 of 6

Habitat Detective

Only a few pairs of Azure Warblers (fictional) are left. Where should we protect habitat?

Computer optional 45–55 min Unplugged ML

Objectives

  • Find patterns in a nest-site table (machine-learning-style thinking, no coding).
  • Predict mystery sites before answers are revealed.
  • Meet an exception that breaks the model — and explain why.

Materials

  • Habitat dataset (print or project)
  • Whiteboard for class rules
  • Optional: shared doc for live voting

Instructions

“You work for a bird conservation group. Figure out where Azure Warblers are most likely to nest.”

Step 1 — Training data (15 min)

Students study sites with known Yes/No nests. Prompt: “If you were a computer, what rules predict a nest?”

Likely pattern: cooler/mild temp + high tree cover + high insects + low disturbance → Yes.

Capture short class rules on the board.

Step 2 — Mystery sites (10 min)

Vote nest / no nest for mystery sites; then reveal.

Step 3 — Mess with them (12 min)

Give a site with high disturbance that still has nests (e.g., nest boxes in a busy park — a factor you didn’t measure).

  • “Our model said no. What went wrong?”
  • Possible answers: hidden factor, small dataset, birds adapted, biased sampling, luck.

Big idea: Data isn’t the whole world. Models only know what we measured.

Wrap (5–8 min)

Preview Module 5: “What if almost all our ‘yes’ nests came from one park?”

Differentiation & assessment

5th–6th: High/Low columns only. · 7th–8th: add confidence (sure / kind of sure / guessing) before reveals.

Assess: written rule + 3 mystery predictions + one hypothesis for the exception.
