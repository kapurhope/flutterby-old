# FlockQuest

Bird conservation trade-off mini-sim for **Flutterby Field School** Module 6 (grades 5–8).

## Run it

Open `index.html` in a browser, or after GitHub Pages is on:

`https://kapurhope.github.io/flutterby/flockquest/`

## Goals students juggle

- Nest success ≥ 75  
- Neighbor conflict ≤ Medium  
- Budget ≤ $100  

Presets, stress events (heat wave, late freeze, bad survey data), and two saved runs for mini-debate.
